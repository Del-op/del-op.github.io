# About

Personal blog on math, logic, physics, and computation, with notes on subjects I find interesting.

**URL:** [https://del-op.github.io](https://del-op.github.io)

## Run Locally

To run the site locally using Jekyll:

```bash
bundle install
bundle exec jekyll serve
```

## Theme

This site uses the [Chirpy](https://github.com/cotes2020/chirpy-starter) theme.
